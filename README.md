# homebrew-hyperb

Homebrew tap for [hyperb](https://github.com/hypereffect/hyperb): a browser for
[hypereffect](https://crates.io/crates/hypereffect) apps, with a GTK4 desktop
app, a terminal app, an Android app and a web app.

Apple Silicon only. The app is unsigned, so the cask clears the quarantine flag
for you.

```
brew install --cask andunieee/hyperb/hyperb
```
